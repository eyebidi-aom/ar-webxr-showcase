# AR 3D Showcase

เว็บแอป Augmented Reality (AR) ที่พอส่องกล้องเจอพื้นจริงปุ๊บ จะสร้าง **"บูธนิทรรศการเสมือนจริง"** ขึ้นรอบตัวผู้ใช้ทันทีแบบอัตโนมัติ — มีโมเดล 3 มิติลอยอยู่ตรงกลาง พร้อมบูธวิดีโอ บูธกราฟ และบูธสไลด์เรียงรอบๆ ให้เดินสำรวจและแตะดูได้เลยโดยไม่ต้องกดปุ่มเปิดทีละอัน สร้างด้วย [A-Frame](https://aframe.io) และ WebXR Hit-Test API

🔗 **เปิดใช้งาน:** เมื่อเปิดใช้งาน GitHub Pages แล้ว จะเข้าถึงได้ที่ `https://<username>.github.io/<repo-name>/`

## ฟีเจอร์

- 📷 **AR วางบูธอัตโนมัติ (Markerless)** — ใช้ WebXR Hit-Test ตรวจจับพื้นจริง พอเจอพื้นปุ๊บ ระบบวางบูธทั้งหมดให้ทันทีโดยไม่ต้องกดปุ่ม "วาง" เอง
- 🏛️ **บูธนิทรรศการรอบโมเดล** — วิดีโอ กราฟ และสไลด์วางเรียงรอบโมเดลตลอดเวลา (ไม่ต้องกดเปิด/ปิดทีละอัน) เดินสำรวจแล้วแตะดูได้เลย
- 🖐️ **อินเตอร์แอคทีฟ** — บีบสองนิ้วเพื่อซูม หรือใช้ปุ่มหมุน/ซูม/ย้ายบูธในแถบเครื่องมือ
- 🎥 **บูธวิดีโอ** — แตะที่จอวิดีโอ (หรือปุ่ม ▶️ ในแถบเครื่องมือ) เพื่อเล่น/หยุดได้ทันที
- 📊 **บูธกราฟ** — แสดงกราฟตัวอย่าง (Chart.js) เป็นพื้นผิวลอยอยู่ในบูธ เห็นได้ตลอดเวลา
- 🖼️ **บูธสไลด์** — แตะที่จอสไลด์ (หรือปุ่ม ‹ › ในแถบเครื่องมือ) เพื่อเลื่อนหน้าก่อน/ถัดไป
- 🧊 **โหมดพรีวิว 3 มิติ** — สำหรับอุปกรณ์ที่ไม่รองรับ WebXR AR (เช่น iPhone) ดูบูธทั้งหมดแบบลอยตรงหน้าได้โดยไม่ต้องใช้กล้อง
- ⚙️ **ตั้งค่าเนื้อหาได้เองจากหน้าเว็บ** — เปลี่ยนโมเดล 3 มิติ วิดีโอ ข้อมูลกราฟ และสไลด์ ได้จากปุ่ม "ตั้งค่า" โดยไม่ต้องแก้โค้ด
- 🎨 UI แบบ Glassmorphism ทันสมัย รองรับภาษาไทย (ฟอนต์ Kanit)

## ข้อกำหนดของอุปกรณ์

โหมด AR เต็มรูปแบบต้องใช้:

- **Chrome บน Android** ที่รองรับ [WebXR Device API](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API) (ARCore)
- การเชื่อมต่อผ่าน **HTTPS** (WebXR/กล้องจะไม่ทำงานบน HTTP ธรรมดา — GitHub Pages เป็น HTTPS อยู่แล้ว)
- อนุญาตสิทธิ์การใช้กล้องเมื่อเบราว์เซอร์ขอ

หากอุปกรณ์ไม่รองรับ (เช่น iPhone/Safari หรือคอมพิวเตอร์เดสก์ท็อป) เว็บจะสลับไปที่โหมด **"ดูตัวอย่าง 3 มิติ (ไม่ใช้กล้อง)"** ให้อัตโนมัติ

## วิธีใช้งาน

1. เปิดลิงก์เว็บไซต์บนมือถือ (Chrome/Android แนะนำ)
2. กด **"เริ่มประสบการณ์ AR"** แล้วอนุญาตให้ใช้กล้อง
3. เลื่อนกล้องช้าๆ ไปทางพื้น จนกว่าระบบจะเจอพื้น — **บูธทั้งหมด (โมเดล + วิดีโอ + กราฟ + สไลด์) จะถูกวางให้อัตโนมัติทันที** ไม่ต้องกดปุ่มวางเอง
4. เดินสำรวจรอบๆ บูธ แล้วแตะที่จอวิดีโอเพื่อเล่น/หยุด หรือแตะที่จอสไลด์เพื่อเลื่อนหน้า (หรือใช้ปุ่มในแถบเครื่องมือด้านล่างแทนก็ได้)
5. บีบสองนิ้วเพื่อซูมเข้า/ออก หรือใช้ปุ่ม ➖ ➕ ↺ ↻ เพื่อย่อ/ขยาย/หมุนทั้งบูธ
6. แตะ **🔄 ย้ายบูธ** เพื่อยกบูธไปวางที่ตำแหน่งพื้นใหม่
7. แตะ **♻️ รีเซ็ต** เพื่อรีเซ็ตขนาด/มุมหมุนกลับค่าเริ่มต้น หรือ **✕** เพื่อออกจากโหมด AR

## การปรับแต่งเนื้อหา (ไม่ต้องแก้โค้ด)

กดปุ่ม **"⚙️ ตั้งค่าวิดีโอ / กราฟ / สไลด์ / โมเดล"** ที่หน้าแรกของเว็บ จะเปิดหน้าต่างตั้งค่าที่ทำได้เองทั้งหมดจากหน้าเว็บโดยตรง:

- **โมเดล 3 มิติ**: วางลิงก์ไฟล์ `.glb` หรืออัปโหลดไฟล์จากเครื่อง พร้อมปรับขนาดเริ่มต้นได้
- **วิดีโอ**: วางลิงก์วิดีโอ หรืออัปโหลดไฟล์จากเครื่อง
- **กราฟ**: แก้ชื่อกราฟ เพิ่ม/ลบ/แก้ค่าแต่ละแท่งได้อิสระ
- **สไลด์**: อัปโหลดรูปภาพได้หลายรูป หรือเพิ่มสไลด์ข้อความเอง ลบทีละสไลด์ได้

กด **"💾 บันทึกและใช้งาน"** เพื่อใช้เนื้อหาใหม่ทันที ระบบจะจดจำการตั้งค่า (ลิงก์ URL และรูปภาพขนาดเล็ก) ไว้ใน**เบราว์เซอร์ของเครื่องนั้น**โดยอัตโนมัติ ให้ครั้งถัดไปที่เปิดเว็บไม่ต้องตั้งใหม่ — **ข้อควรทราบ:** การตั้งค่านี้จำไว้เฉพาะเบราว์เซอร์/อุปกรณ์ที่ตั้งเท่านั้น ไม่ได้เปลี่ยนเนื้อหาที่คนอื่นเห็นเมื่อเปิดลิงก์เดียวกันจากเครื่องอื่น ส่วนไฟล์วิดีโอ/โมเดลที่อัปโหลดจากเครื่อง (ไม่ใช่ลิงก์ URL) จะใช้ได้เฉพาะตอนนั้น รีเฟรชหน้าแล้วต้องอัปโหลดใหม่ (ไฟล์เล็กพอจะถูกจำไว้อัตโนมัติเช่นกัน) กด **"↩️ รีเซ็ตค่าเริ่มต้น"** เพื่อล้างค่าที่ตั้งไว้และกลับไปใช้ไฟล์ตัวอย่างเริ่มต้น

โมเดลตัวอย่าง (Astronaut) และวิดีโอตัวอย่างที่มาพร้อมเว็บเป็นไฟล์สาธารณะสำหรับ demo เท่านั้น แนะนำให้เปลี่ยนเป็นไฟล์ของคุณเองผ่านหน้าตั้งค่าก่อนใช้งานจริง

## เทคโนโลยีที่ใช้

- [A-Frame 1.5](https://aframe.io/) — WebVR/WebXR framework
- [WebXR Hit-Test API](https://immersive-web.github.io/hit-test/) (ผ่าน component `ar-hit-test` ของ A-Frame) — ตรวจจับพื้นแบบ markerless
- [Chart.js](https://www.chartjs.org/) — เรนเดอร์กราฟเป็นพื้นผิว (texture) ในฉาก 3 มิติ
- WebXR DOM Overlay — แสดง UI ปุ่มควบคุมทับบนภาพกล้องจริง

> หมายเหตุ: การวางโมเดลบนพื้นแบบ markerless (ไม่ใช้มาร์กเกอร์ภาพ) ใช้ความสามารถ WebXR Hit-Test ของเบราว์เซอร์โดยตรง ซึ่งรองรับเฉพาะ Chrome บน Android ปัจจุบันไลบรารี AR.js (แบบมาร์กเกอร์/ตำแหน่ง GPS) ยังไม่รองรับการตรวจจับพื้นแบบนี้ จึงเลือกใช้ความสามารถ WebXR ในตัวของ A-Frame แทนสำหรับโหมดนี้
